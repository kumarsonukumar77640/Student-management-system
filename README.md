# 🎓 Student Management System (Django + MySQL)

## 📌 Description
Ye ek Student Management System web application hai jo Django framework aur MySQL database ka use karke banaya gaya hai. 
Isme user sabse pehle registration karega aur login karega uske bad CRUD operation perfrom kar sakta hai.
Is system se admin students ka data add, update, delete aur view kar sakta hai.
isme search features hai student ko multiple condtion ke according search bhi kar sakte hai example- name or email.


---

## 🚀 Features
- Student Login Authentication
- Student registration
- Search Student
- Add new student details
- Update student information
- Delete student record
- View all students list



## 🛠️ Tech Stack
- Python 🐍
- Django 🌐
- MySQL 🗄️
